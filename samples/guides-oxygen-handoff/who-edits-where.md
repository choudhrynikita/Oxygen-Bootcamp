# Who edits where

| Job | Surface | Why |
|---|---|---|
| Fix a step a reviewer flagged | Guides web editor | SME is already in the browser review |
| Rebuild a map with submaps and keys | Oxygen desktop | Maps Manager, completeness, Master Files |
| Run Schematron against a house style | Oxygen desktop | Schematron + Quick Fixes |
| Check in after a desktop edit | Guides | Checkout / check-in mental model |
| Campaign landing page | AEM Sites | Not DITA |

PID to ask an admin about (do not guess in production): `com.adobe.fmdita.xmleditor.config.XmlEditorConfig` key `xmleditor.editinoxygen=true`. Verify in the Experience League article “Configure Edit in Oxygen”.
