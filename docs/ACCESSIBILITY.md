# Accessibility

- Semantic headings. Skip link on every page. Main landmark.
- Body ≥ 16px on mobile. Line-height 1.5–1.7.
- Contrast ≥ 4.5:1 for body text. Status is never color-only (streak dots use fill + label).
- Focus rings on every control. Named icon buttons (`aria-label`).
- Keyboard: pager, quests, timer (pauseable; timer is not the only way to complete a block).
- Watch-for list under every video (what to look at, not a transcript dump).
- Teaching-point alt text on wireframes. Callouts have text equivalents.
- `prefers-reduced-motion`: instant state, no celebration animation, no confetti.
- No autoplay. Sound off by default.
- Game toasts are polite and dismissible.
- 375px day pages do not horizontal-scroll except labeled XML regions (`overflow-x: auto` + “XML, scroll sideways”).
- Quiz options are full buttons, not color-only chips.

Manual pass: Path 1–90, Today, Daily Burst, Session timer, Settings text scale, export.
