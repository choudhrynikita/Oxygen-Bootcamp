# Content policy

This bootcamp teaches with original prose, original figures (labeled wireframes), and **links** to vendor manuals. It does not paste manuals.

## Do

- Rewrite the teaching. Quote a few lines max, then link the source.
- Reuse original v1 LMS prose from `legacy/assets/curriculum.js`.
- Name controls the way the official UI names them. If unsure, write “verify this label in your version” and link the guide.
- Prefer v1 YouTube ids. Every UI lesson has a live Source box.
- Keep families distinct: Oxygen (Syncro Soft) vs AEM Sites vs AEM Guides. There is no product called “AEM Oxygen XML Editor.”
- Label mocks as mocks. AEM without an instance uses official video + labeled mocks + a field log.
- Track volume in [CONTENT_BUDGET.md](../CONTENT_BUDGET.md). Text and small diagrams in git. Screenshots and packs in LFS or object storage if they grow. Videos by official URL.

## Do not

- Scrape or paste official Oxygen manuals, Experience League books, DITA specs, or vendor PDFs as full lessons.
- Dump 5–6 GB into git.
- Ship lorem, `TODO`, placeholder video ids, or dead buttons.
- Use stock photos as product UI.
- Award XP for page views or badges for watching a video.
