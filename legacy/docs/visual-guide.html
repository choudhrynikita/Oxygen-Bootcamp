2. Author mode canvas

  • Toolbar cluster changes with the framework (DITA vs DocBook).
  • Styles dropdown: default + layers (Hints, Inline actions, Full tags).
  • Enter = content completion, not “new paragraph at all costs.”
  • Red squiggles = validation. Read the message at the bottom.

Demo page: WYSIWYG XML Editing

3. Maps Manager

  • Tree = publication structure, not the filesystem.
  • Root map setting (toolbar) controls key resolution.
  • Validate and Check for Completeness lives here.
  • Edit Properties on a topicref for keys, navtitle, linking.

Demo page: DITA Maps Manager

4. Validation strip

Bottom panel lists errors by file. Double-click jumps to the node. A yellow light bulb is a Quick Fix.

5. Transformation dialog

Configure Transformation Scenario → filter “DITA Map”. Output folder should be outside source (e.g. out/).
